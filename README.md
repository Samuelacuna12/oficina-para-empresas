# Oficina para empresas

Plantilla de oficina interactiva con equipo 3D, departamentos, pipeline de tareas y un diagnóstico inicial para adaptar el equipo a los procesos de cada negocio. Creada por Samuel Acuña; esta versión está preparada para que otras empresas la personalicen.

Incluye un cuestionario de optimización, puestos configurables y flujo local de tareas. Consulta la guía de instalación y privacidad en el repositorio.
